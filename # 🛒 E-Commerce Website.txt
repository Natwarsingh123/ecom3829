# 🛒 E-Commerce Website

A modern and responsive eCommerce platform built to simplify online shopping. This project provides a seamless user experience with product browsing, shopping cart functionality, secure checkout, order tracking, and an admin dashboard for managing products and customers.

---

## 📌 Features

### Customer Features
- User Registration & Login
- Product Catalog
- Product Search
- Category Filtering
- Shopping Cart
- Secure Checkout
- Order Tracking
- Responsive Design

### Admin Features
- Product Management
- Inventory Control
- Order Management
- Customer Management
- Dashboard Analytics

---

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap (Optional)
- REST APIs (Future Integration)
- Payment Gateway Integration (Future Scope)
